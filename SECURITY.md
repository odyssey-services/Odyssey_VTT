# Security

Do not report security issues, secrets, or private findings in GitHub issues, pull requests, commits, logs, screenshots, or artifacts.

Until the owner publishes a dedicated private reporting address, report security concerns through the private channel already established with the project owner. If no private channel is available, request one without disclosing details publicly.

## Never Commit

- passwords, tokens, credentials, certificates, keys, or `.env` files;
- private product documentation or current-context archives;
- private campaign data, hidden GM data, private chat, or personal data;
- full local machine paths, diagnostic dumps, crash dumps, or logs containing sensitive content;
- Unity license or activation data.

If a secret or private file reaches a remote repository, stop work, notify the owner privately, rotate affected secrets, and follow an approved history-rewrite incident procedure. Deleting a later commit is not sufficient.
